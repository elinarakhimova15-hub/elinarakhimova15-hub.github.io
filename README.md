# Храм дробей

Автономная браузерная математическая игра для учеников 5–6 классов.

## Как запустить

Откройте `index.html` в современном браузере. Для публикации загрузите все файлы из этой папки в корень статического сайта.

Игра не требует аккаунта, сервера, базы данных или внешних библиотек. Она не собирает и не отправляет персональные данные.

## Управление

- `A` / `D` или стрелки — движение;
- пробел, `W` или стрелка вверх — прыжок;
- `E` — открыть математическое испытание;
- на телефоне используются экранные кнопки.
